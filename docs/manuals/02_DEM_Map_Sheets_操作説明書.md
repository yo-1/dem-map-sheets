# DEM Map Sheets｜操作説明書
対象：v0.2.1（正式版）／基準実装：main `3c819554e2b5538704a44fa7e700b24323e51c3a`／2026-11-10

## 1. 事前準備
QGIS 3.44〜3.99、プラグイン配布ZIP、十分なディスク空き容量、処理対象のDEMを準備する。LAS/LAZ/COPCではPDALの導入・実行可能性も確認する。元データはバックアップし、最初は少数ファイルで試す。

## 2. インストール
配布ZIPはGitHub Release v0.2.1（https://github.com/yo-1/dem-map-sheets/releases/tag/v0.2.1）から取得する。QGISのプラグイン管理画面で「ZIPからインストール」を選択し、配布ZIPを指定する。プラグインを有効化する。専用画面はラスタメニュー「DEM Map Sheets」またはツールバーのアイコン（黒地に地形断面を描いた専用アイコン）から、Processingアルゴリズムはプロセシングツールボックスから起動する。専用画面では誤操作防止のため、数値入力欄とプルダウンはマウスホイールで変更できない。

## 3. 最初の演習：GeoTIFF 2枚を統合
1. 同じ高さ基準のGeoTIFFを2枚用意し、一部が重なる範囲を選ぶ。
2. 入力形式を「標高ラスタ（GeoTIFF・TIFF+TFW・IMG・ASC）」に設定する。
3. 入力ファイルで2枚を選ぶ。または入力フォルダーを指定する。
4. 出力CRSに対象地域の正しい平面直角座標系を指定する（必須。未設定では処理を開始できない）。
5. 出力セルサイズを例として1.0mに設定する。
6. 重複時の優先順を指定する。入力順によって結果が変わるため順序を記録する。
7. 初回はTerrainRGB生成をオフにする（既定はオン）。
8. 出力先親フォルダーを指定して実行する。実行ごとに `demmap_<日時>_<6桁>` のフォルダーが自動作成され、成果物はその中に入る。
9. その中の `02_merged_dem.tif` をQGISに読み込み、範囲・CRS・セルサイズ・標高値・NoData・接合部を確認する。
10. 同じフォルダーの `run.json` で `status` が `completed` であることを確認する。

## 4. 大量ファイル・複数メッシュ
入力フォルダーを指定し、必要に応じ「サブフォルダーも検索する」を有効にする。入力形式と拡張子が一致することを確認する。数百件以上は少数件で試験してから範囲を拡大する。入力形式が混在する場合は形式ごとに変換し、変換済みGeoTIFFを最後にまとめる。

## 5. 国土地理院DEM ZIP/XML
入力形式を国土地理院DEMにし、ZIPまたはXMLを選択する。CRS・セルサイズ・出力先を設定する。まず少数ファイルで標高値と欠測の扱いを確認する。

## 6. LAS/LAZ/COPC
入力形式を点群にし、PDAL実行ファイルを設定する（PATHにあれば省略可）。地表面の取り出し方は「分類済み（指定分類コードを抽出）」「地表面点のみのデータ」「自動分類（SMRF）」から選ぶ（既定は分類済み、分類コードの既定は2）。補間方法（既定はIDW）と半径（既定は2.0m）を確認し、地物残存・欠測・点密度を検査する。

## 7. 森林航空レーザ成果
LEM／CSV格子／TIFF等の形式を選択し、座標順、格子間隔、LEM倍率、NoData等を元成果の仕様に合わせる。CSV格子の座標がセル中心か左上角かは「森林格子座標の解釈」で指定する（「指定なし」の場合はセル中心として扱う）。ZIP内構成やメタデータが正しいか少数ファイルで試す。

## 8. XYZ/CSV/TXT
入力CRSを明示し、区切り文字、文字コード（既定は utf-8-sig。cp932のデータでは `cp932` と指定する。ただし実データでの検証は未実施）、ヘッダー読み飛ばし、X/Y/Z列、座標順、規則格子／不規則点を設定する。日本の測量成果で「X=北・Y=東」とGIS座標の「X=東・Y=北」を混同しない。格子点がセル中心か格子交点かを確認する。

## 9. 重複優先とTerrainRGB
自動優先ではメタデータCSV/JSON（列：`source,survey_year,accuracy_m,ground_density`）の計測年度・精度等を指定し、`run.json` の `priority_selection` に記録された採用元を確認する。TerrainRGBを生成する場合はズーム範囲を小さく始め、`03_terrainrgb_xyz/{z}/{x}/{y}.png` を確認する。

## 10. 設定保存・再利用
専用画面の下部にある「設定を保存」「設定を読み込む」ボタンで、パラメータ一式をJSONファイルに保存・再利用できる（保存時の既定ファイル名は `dem_settings.json`）。読み込み時は、現在のPCで解釈できないCRSが含まれていると読み込み自体が中止され、現在の設定は変更されない。保存された入力ファイルのうち現在のPCに見つからないものは、読み込み完了時に一覧表示される。読み込み後は入力パス・出力先・CRS・標高基準を再確認する。動的な式を含む設定は保存できない。

## 11. 失敗時の対応
入力がない（「入力ファイルまたは入力フォルダーを指定してください。」）→形式・拡張子・再帰探索を確認。出力CRS未設定（「出力CRSを指定してください。」）→出力の平面直角座標系を設定する。CRS不明→元データのCRSを確認。PDAL不在→実行ファイルを指定。PDALが日本語パスを扱えずエラーになる→出力先を英数字のみのパスにするか、環境変数 `DEM_MAP_SHEETS_TEMP` に英数字のみの作業フォルダーを指定する。読めない入力ラスターがある→既定では処理が停止する。警告して続行する場合は「読み込めない入力ラスターを警告してスキップする」を有効にする（スキップした入力は `run.json` に記録される）。画素上限超過→範囲分割またはセルサイズを見直す。高さ基準不一致→事前変換。切り分けには「中間変換ファイルを残す」を有効にして再実行する。失敗・キャンセルのマニフェストとログを保存する。
