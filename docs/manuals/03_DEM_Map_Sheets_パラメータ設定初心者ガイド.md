# DEM Map Sheets｜パラメータ設定・初心者ガイド
対象：v0.2.1（正式版）／基準実装：main `3c819554e2b5538704a44fa7e700b24323e51c3a`／2026-11-10

## 1. 初心者向け最小設定
最初は同じ高さ基準のGeoTIFFを2枚だけ用意する。「入力形式＝標高ラスタ」「入力＝2枚」「出力CRS＝地域に合う平面直角座標系」「セルサイズ＝元データに合う値（例1m）」「重複優先＝後に並ぶ入力を優先（既定の自動判定ではなく入力順の方が結果を予測しやすい）」「TerrainRGB＝オフ」「出力先＝空き容量のあるフォルダー」で実行する。

## 2. 入力関連
- 入力形式：ラスタ／国土地理院DEM／標高テキスト／点群／森林航空レーザ成果から選ぶ。1回の実行では形式を統一する。
- 入力ファイル：複数指定可能。入力フォルダーと使い分ける。入力ファイルと入力フォルダーの両方を指定した場合は入力ファイルが使われ、フォルダーは使われない。
- 入力フォルダー：大量ファイル向け。サブフォルダー検索のオン／オフに注意（既定はオン）。
- 入力CRS：特にテキスト・LEM等、CRSが埋め込まれていないデータで必須。

## 3. 出力関連
- 出力CRS：対象地域に適合するEPSGコード。測地系・系番号を確認する。必須項目で、未設定では処理を開始できない。
- 出力セルサイズ（m）：0.5m、1m、5mなど（設定範囲は0.01〜100m、既定は1.0m）。入力より細かくしても新しい地形情報は増えない。
- 出力先親フォルダー：作業ファイルと完成ファイルに十分な容量を確保する。実行ごとに `demmap_<日時>_<6桁>` のフォルダーが自動作成され、成果物はその中に入る。
- 高さ基準：入力標高の基準（VERTICAL_MODE）は記録用であり自動高さ変換は行わない。「標高基準の追加入力」に自由記述すると、選択よりもそちらが優先して記録される。

## 4. 重複範囲
- 入力順優先：「後に並ぶ入力を優先」か「先に並ぶ入力を優先」かを指定。入力順の管理が必要。
- 自動優先（既定）：2500図郭ごとに、計測年度が新しい順→精度が高い（accuracy_mが小さい）順→グラウンド点密度が高い順→2500図郭充足率が高い順で採用元を判定する。判定は優先メタデータの品質に依存する。対象図郭数の上限（既定100,000）を超える指定はできない。
- メタデータCSV例（列名はこの4列で固定。`source` は絶対パスで照合され、ファイル名が一意な場合のみファイル名でも照合される）：
```csv
source,survey_year,accuracy_m,ground_density
dem_2025.tif,2025,0.15,8
dem_2022.tif,2022,0.25,4
```

## 5. 入力形式別の追加設定
### GeoTIFF・ラスタ
CRS、NoData、解像度、元ファイルのTFWの有無を確認。入力NoData値を明示する場合は「入力NoData値」に指定する（空欄なら入力ファイル自身の定義を使う）。

### 国土地理院DEM
ZIP/XMLの種類、元標高基準、欠測コード、出力セルサイズを確認。

### XYZ/CSV/TXT
区切り文字（既定はカンマ）、文字コード（既定は utf-8-sig。cp932のデータでは `cp932` と指定する。ただし実データでの検証は未実施）、ヘッダー行の読み飛ばし（既定は1行）、X/Y/Z列（既定は1,2,3列）、座標順（既定は東,北）、規則格子か不規則点か、セル中心と格子交点の規約を確認。座標系不明のまま実行しない。なお座標順の既定は森林航空レーザCSVとは逆（森林は北,東が既定）なので、形式を取り違えないこと。

### LAS/LAZ/COPC
PDAL実行ファイル、分類済み地表面点（通常分類2）を使うか、SMRF等で分類するか、補間方式（既定はIDW）・半径（既定は2.0m）を指定。出力標高の妥当性を点群と比較する。

### 森林航空レーザ
LEM座標倍率（既定はauto）、格子間隔（既定はauto）、座標順（北,東など。既定は北,東）、森林格子座標の解釈（「指定なし」の場合はセル中心。成果の座標がセル左上角を指す場合は `upper_left` を選ぶ）、NoData（森林成果の既定NoData、既定は-9999。出力DEM自体のNoDataは別途 -999999 で固定）を成果仕様書と照合する。実際の成果CSVの座標規約（セル中心か左上角か）は未確認のため、仕様書で必ず確認する。

## 6. TerrainRGB
必要な場合だけオンにする（既定はオン）。最小ズーム（既定2）・最大ズーム（既定18）とタイル数上限（候補枚数上限、既定1,000,000）を小範囲で確認する。Web地図の標高符号化用であり、見た目の彩色標高図ではない。

## 7. 容量・性能
概算画素数＝幅(m)÷セルサイズ(m) × 高さ(m)÷セルサイズ(m)。1m格子の5km×5kmは2,500万画素。処理には画素数上限（出力・入力とも2,500万画素）と入力ファイル数上限（100,000件）があり、メモリ・ディスク容量にも注意し、広域は分割処理を検討する。

## 8. 初心者の確認チェック
- 対象地域の正しいCRSを選んだか
- 元データの高さ基準は同じか
- X/Yの順序は正しいか
- 重複優先は意図どおりか
- `02_merged_dem.tif` をQGISで開けるか
- `run.json` の `status` は `completed` か
- 接合部・欠測・標高値を確認したか

## 9. 注意
本書のパラメータ名・既定値・選択肢は、v0.2.1の実装（main `3c81955`）と付表のとおり照合済みである。ただし画面表示そのものとの照合（スクリーンショット確認）は未実施で、大量実データ処理とWindows GUIの最終試験は未完了。未確認事項の全体は操作説明書 §12 を参照する。
