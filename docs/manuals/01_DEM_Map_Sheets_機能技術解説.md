# DEM Map Sheets｜機能・技術解説書
対象：v0.2.1（正式版）／基準実装：main `3c819554e2b5538704a44fa7e700b24323e51c3a`／2026-11-10

## 1. 目的
DEM Map Sheetsは、異なる形式・図郭・メッシュに分割された標高データをQGISで取り込み、座標系とセルサイズを統一し、複数のDEMを1枚のGeoTIFFへ統合するためのQGISプラグインである。従来、ファイル形式変換、投影変換、リサンプリング、モザイク作成を別々のツールで行っていた作業を、設定と実行記録を伴う一連の処理にまとめる。

## 2. 主な機能
- 複数ファイル選択／フォルダー指定／サブフォルダー再帰探索
- 入力：GeoTIFF、TIFF+TFW、IMG、ASCなどの標高ラスタ
- 入力：国土地理院DEMのZIP/XML
- 入力：XYZ/CSV/TXTの標高テキスト（座標順・列番号・区切り等を指定）
- 入力：LAS/LAZ/COPC点群（PDAL利用）
- 入力：森林航空レーザ成果（LEM、CSV格子、TIFF+TFW、GeoTIFF、ZIP）
- 出力CRS・セルサイズの統一、入力別DEMの生成、重複優先順を指定したモザイク
- 統合GeoTIFF（`02_merged_dem.tif`）およびTerrainRGB XYZタイル（既定で生成。標高の符号化式は H=-10000+(R*65536+G*256+B)*0.1）
- 実行条件・処理結果のマニフェスト `run.json`

## 3. 基本処理
入力を列挙→形式別読込／必要に応じPDALによる地表面抽出・補間→指定CRSへの変換・解像度統一→重複範囲の採用元選定→統合GeoTIFF出力→必要に応じTerrainRGBを生成する。図郭に基づく優先選定は出力を図郭ごとに分割する機能とは異なる。

## 4. 重複部分の扱い
入力順の先／後優先、または自動判定を選択できる。自動判定は2500図郭ごとに行い、計測年度が新しい順→精度が高い（accuracy_mが小さい）順→グラウンド点密度が高い順→2500図郭充足率が高い順に採用元を決める。メタデータが不足する項目は最低位として扱われる。優先メタデータCSV/JSON（列：`source,survey_year,accuracy_m,ground_density`）を併用でき、採用元と順位は `run.json` の `priority_selection` で監査できる。

## 5. 注意点と制約
- 高さの基準（標高・楕円体高など）の自動変換は行わない。異なる高さ基準をそのまま結合しない。
- 1回の実行で入力形式を1種類選択する設計。混在形式は形式別にGeoTIFF化してから統合する。
- 処理には画素数上限があり（出力・入力とも1回あたり2,500万画素、入力ファイル数は100,000件まで）、県全域の高解像度DEMを無制限に一括生成できるわけではない。
- TerrainRGBはRGBで標高を符号化したタイルで、CS立体図や陰影起伏図そのものではない。
- 入力データの品質、欠測、測地系、境界部の段差は別途検証が必要。
- Windows／QGIS 3.44での検証はエンジン・API経由を中心に実施済みだが、GUIダイアログ経由の一部操作の再実行と画面表示の照合は未確認である。実LAS/LAZデータ、cp932のLEM、大量実データの連続処理も未確認であり、本書では検証済みとしていない。

## 6. 適用例
航空レーザ測量の分割DEMを測量区ごとに統合、国土地理院DEMを複数メッシュから統合、森林レーザ成果の形式統一、複数年度の重複DEMの採用元管理など。

## 7. 成果物の確認
`run.json` の完了状態（`status` が `completed` か）、統合GeoTIFFのCRS・解像度・範囲・NoData（出力DEMのNoDataは -999999 で、`run.json` の `output_nodata` に記録される）、入力DEMとの重なり、境界の段差、採用優先順位を確認する。失敗・キャンセル時の中間ファイルを完成品として利用しない。
