- merge_geotiffs: VRT生成後のWarp/Translate例外時に一時VRTが残る可能性。try/finallyでのクリーンアップを検討。
- SMB共有切断: _network_callの再試行・中止挙動と再実行時の出力整合性を確認。
- GitHub Actions: 既存画面ではpush/PRの2実行成功。今回の追加コミット後のCI結果は別途確認が必要。
- Windows/QGIS 3.44のGUI・Processing9件、実業務データ、県全域負荷試験は未実施。validation/WINDOWS_RC4.mdに従い最後に実施する。
