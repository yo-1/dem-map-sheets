# DEM Map Sheets

**図郭対応DEM作成・タイル化プラグイン v0.2.1**

CS Map Sheets をベースに、CS立体図の描画処理を外して「DEMを作る・そろえる・マージする・配信用XYZへ変換する」ことに特化した QGIS 3.44 プラグインです。

## 入力

- 標高ラスタ：GeoTIFF / TIFF+TFW / IMG / ASC / VRT
- 国土地理院 基盤地図情報 数値標高モデル：ZIP / XML
- 標高テキスト：XYZ / CSV / TXT（規則格子またはPDAL補間）
- 点群：LAS / LAZ / COPC（PDAL必要）
- 森林航空レーザ成果：LEM + CSV/TXTメタデータ、CSV/XYZ規則格子、TIFF+TFW、GeoTIFF、ZIP

## 出力

1. `01_source_dem/dem_XXXXX.tif` — 入力を共通CRS・セルサイズへ正規化したGeoTIFF DEM
2. `02_merged_dem.tif` — 全入力をマージしたFloat32 GeoTIFF DEM
3. `03_terrainrgb_xyz/{z}/{x}/{y}.png` — TerrainRGB XYZ（EPSG:3857）
4. `run.json` — 入力条件、CRS、セルサイズ、重複優先順、処理結果

TerrainRGB は次式です。

`H = -10000 + (R*65536 + G*256 + B) * 0.1`

## 重要な注意

- 出力DEMのNoData値は「出力DEMのNoData値」で指定できます（既定は -9999）。Float32で正確に表せる有限の値を指定してください。実際に使われた値は run.json の `output_nodata` に記録されます。
- 入力側の欠測判定は、入力自身の定義（GeoTIFF等のバンドNoData、source_nodata の指定、LEM・GSI・森林成果の形式定義）だけで行います。定義が無いラスタについて -9999 や -999999 を欠測と推測することはしません。定義が無く、非有限セル（NaN等）も無いラスタは従来どおりエラーで停止します。
- 入力ラスタの NaN・±inf セルは標高値ではないため欠測として扱い、出力NoData値に変換されます。優先順位の高い入力が NaN のセルでは、下位の有効値が補完されます（欠測部分への有効値のみの補完は従来どおりです。補間による穴埋めは行いません）。
- 入力に、出力NoData値とちょうど一致する有効な標高セルが含まれている場合、そのセルは出力ではNoDataとして読み取られてしまいます。処理は止めませんが、件数を数えて警告し、run.json（`nodata_value_collisions`）に記録します。必要に応じて出力NoData値を変更してください。
- 欠測域の境界はバイリニア補間の影響を受けます。カーネルに触れるセルは丸ごとNoDataになるため、欠測域は入力との整列やGDALのバージョンにより1セル前後広がったり狭まったりします。欠測域に標高値が作り出されることはありません。
- TerrainRGBタイルの欠測表現はタイル仕様で -9999 と固定されており、出力DEMのNoData値とは連動しません（有効な -9999 m のセルとはアルファ値で区別されます）。
- 出力先フォルダー名に日本語などの非ASCII文字が含まれていても処理できます。PDALが読み書きする中間ファイルは内部でASCIIの作業領域に置かれ、最終成果物は指定の出力先に保存されます。
- 鉛直基準の変換は行いません。新しいEPSGデータセットでは水平CRS（EPSG:6668等）の名称がJGD2011からJGD2024へ変わっていますが、これは名称変更のみで、CRSの定義と座標値は変わりません。一方、標高成果の鉛直基準はこれとは別の事項であり、本ツールでは変換しません。標高成果の基準は別途確認してください。
- 規則格子テキスト（XYZ/CSV）では標本点を画素中心として扱います。標本点が出力セルの格子線上に並ぶ配置では、位置合わせ（targetAlignedPixels）とバイリニア補間により標本値が平均化され、半セル分の位相ずれとして現れます。この配置の検出・警告は未実装（既知の未解決事項）です。
- LAS/LAZ/COPCおよび不規則点のDEM化にはPDALが必要です。
- 重複部は自動判定、先入力優先、後入力優先から選択できます。
- 広域処理ではXYZタイル枚数が非常に多くなるため、`XYZ候補枚数上限`で安全停止します。

## 重複DEMの自動優先選定（v0.2.0）

重複時の優先順で「自動判定」を選ぶと、**国土基本図2500図郭（2,000m×1,500m）ごと**に候補DEMを評価します。
判定は次の辞書順で、上位の条件が異なる場合はそこで順位を確定します。

1. **計測年度**：新しいほど優先
2. **精度**：`accuracy_m`（m）が小さいほど優先
3. **グラウンド点密度**：`ground_density`（点/m²）が大きいほど優先
4. **図郭充足率**：当該2500図郭内の有効DEM画素率が大きいほど優先

値が不明な項目は推定で埋めず、同じ比較項目では既知値より下位に置きます。LEMの「測量年」はメタデータから自動取得します（異なる年度が混在するアーカイブは不明扱い）。「地表面点のみのデータ」と明示した単一LAS/LAZでは、出力CRSがメートル単位の投影座標系の場合に点数と範囲から平均点密度を算出します。それ以外の精度・密度は任意のCSV/JSON台帳で指定します。

CSV列は `source,survey_year,accuracy_m,ground_density` です。`priority_metadata_example.csv` を参照してください。`source` は入力のフルパスを推奨し、一致しない場合は一意なファイル名でも照合します。

自動判定では、各図郭について全候補の順位、計測年度、精度、グラウンド点密度、図郭充足率、最上位ソースを `run.json` の `priority_selection.decisions` に記録します。最上位ソースのNoData部分には次順位のDEMが補完されるため、順位判定と欠測補完の両方を再現できます。

自動判定にはJGD2011/JGD2000の平面直角座標系（I～XIX系）が必要です。出力セルサイズは2500図郭の2,000m×1,500mを整数画素に分割できる値を指定してください（例：0.5m、1m、2m、5m、10m）。
