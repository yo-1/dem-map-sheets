
## NoDataの扱い（次期版）

出力DEMのNoData値は、入力側の「入力NoData値」とは別に「出力DEMのNoData値」で指定します（既定 -9999）。指定した値は設定の保存・読込の対象です。入力の欠測は入力自身の定義でのみ判定され、出力では指定したNoData値に付け替えられます。NaNセルも欠測として扱われます。入力に、出力NoData値と一致する有効な標高セルがある場合は、対象入力・衝突値・件数を示してエラーで停止します。TerrainRGBタイルの欠測表現（-9999）はタイル仕様で固定で、出力NoData値とは連動しません。

## 設定の保存・読込（rc2）
ツールバーのDEM Map Sheetsボタン、またはラスタメニューから開く専用画面の「設定を保存」「設定を読み込む」を使用します。プロセシングツールボックスの標準画面には保存・読込ボタンはありません。JSONへCRS・入力パス・出力先・全処理条件を保存します。読込後にパスと値を確認して実行してください。標高基準は選択式で、不明・未確認が既定です。追加入力は選択より優先し、旧VERTICALパラメータとの互換性を維持します。水平CRSから鉛直基準は推測しません。鉛直CRSや元データからの自動取得は今回未実装です。
